> **Status:** Draft for team approval

## Data Classification Legend

| Label | Meaning in Stage 1 |
|-------|---------------------|
| **REAL DATA** | User-entered content (expense amounts, notes, trip preferences) |
| **MOCK DATA** | Bundled JSON/catalog representing destinations, activities, etc. |
| **SIMULATED DATA** | Generated at runtime by safety/adaptation services (e.g. risk scores) |
| **PLACEHOLDER DATA** | Static UI filler where feature is stubbed |

---

## 1. Destination

**Purpose:** Represents a discoverable place (city/region/spot) the user can plan a trip to.

**Data source (Stage 1):** MOCK DATA

| Field | Type | Required | Description / Allowed values |
|-------|------|----------|------------------------------|
| `destinationId` | String | Yes | Unique ID, e.g. `"dest_shimla"` |
| `name` | String | Yes | Display name |
| `region` | String | Yes | State/region, e.g. `"Himachal Pradesh"` |
| `country` | String | Yes | Default `"India"` |
| `description` | String | Yes | Short marketing/description copy |
| `imageUrl` | String | Optional | Asset path or URL (PLACEHOLDER acceptable) |
| `tags` | List\<String\> | Yes | e.g. `["mountain", "culture", "food"]` |
| `safetyBaselineScore` | int | Yes | 0–100; baseline safety rating |
| `isVerified` | bool | Yes | Verified-style flag for scam-free pitch |
| `averageDailyCostInr` | int | Optional | Transparent pricing hint |
| `highlights` | List\<String\> | Optional | Key attractions |

**Relationships:**
- One `Destination` → many `ItineraryItem` (via itinerary)
- Referenced by `Trip.primaryDestinationId` and `RiskAlert.affectedDestinationId`

**Example:**
```json
{
  "destinationId": "dest_shimla",
  "name": "Shimla",
  "region": "Himachal Pradesh",
  "country": "India",
  "description": "Hill station with colonial heritage and mountain views.",
  "imageUrl": "assets/mock/images/shimla.jpg",
  "tags": ["mountain", "heritage", "family"],
  "safetyBaselineScore": 82,
  "isVerified": true,
  "averageDailyCostInr": 3500,
  "highlights": ["Mall Road", "Jakhoo Temple", "Kufri day trip"]
}
```

## 2. TripPreferences

**Purpose:** User inputs collected during trip planning (before trip entity is created).

**Data source (Stage 1):** REAL DATA (user input)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `startDate` | String (ISO date) | Yes | `"2026-09-01"` |
| `endDate` | String (ISO date) | Yes | Must be >= startDate |
| `travelerCount` | int | Yes | >= 1 |
| `budgetInr` | int | Optional | Total trip budget |
| `interestTags` | List\<String\> | Optional | e.g. `["food", "culture"]` |
| `travelerName` | String | Optional | Local display name (no auth in Stage 1) |

**Relationships:** Used as input to create `Trip`

---

## 3. Trip

**Purpose:** The planned or active trip session — central aggregate root for Stage 1.

**Data source (Stage 1):** REAL DATA (created from preferences) + references MOCK destinations

| Field | Type | Required | Description / Allowed values |
|-------|------|----------|------------------------------|
| `tripId` | String | Yes | Unique ID |
| `primaryDestinationId` | String | Yes | Current main destination |
| `originalDestinationId` | String | Yes | First chosen destination (before adaptation) |
| `preferences` | TripPreferences | Yes | Embedded or referenced |
| `status` | String | Yes | `"planned"` \| `"active"` \| `"adapted"` \| `"completed"` |
| `createdAt` | String (ISO datetime) | Yes | |
| `updatedAt` | String (ISO datetime) | Yes | |
| `itineraryId` | String | Optional | Current itinerary |
| `previousItineraryId` | String | Optional | Before last adaptation |

**Relationships:**
- One `Trip` → one current `Itinerary`
- One `Trip` → many `RiskAlert`
- One `Trip` → many `Expense`
- One `Trip` → many `Memory`
- One `Trip` → many `TimelineEvent`

**Example:**
```json
{
  "tripId": "trip_001",
  "primaryDestinationId": "dest_shimla",
  "originalDestinationId": "dest_shimla",
  "preferences": {
    "startDate": "2026-09-01",
    "endDate": "2026-09-04",
    "travelerCount": 3,
    "budgetInr": 25000,
    "interestTags": ["culture", "food"],
    "travelerName": "Prashanth"
  },
  "status": "active",
  "createdAt": "2026-08-11T10:00:00+05:30",
  "updatedAt": "2026-08-11T10:00:00+05:30",
  "itineraryId": "itin_001"
}
```

## 9. RiskAlert

**Purpose:** User-facing alert when safety condition changes significantly.

**Data source (Stage 1):** SIMULATED DATA (triggered by demo scenario or service)

| Field | Type | Required | Description / Allowed values |
|-------|------|----------|------------------------------|
| `alertId` | String | Yes | Unique ID |
| `tripId` | String | Yes | |
| `affectedDestinationId` | String | Yes | |
| `previousRiskLevel` | String | Yes | `"low"` \| `"moderate"` \| `"high"` \| `"critical"` |
| `currentRiskLevel` | String | Yes | Same allowed values |
| `title` | String | Yes | Short alert headline |
| `message` | String | Yes | Detail for user |
| `recommendedAction` | String | Yes | `"monitor"` \| `"delay"` \| `"adapt_trip"` \| `"cancel_activity"` |
| `createdAt` | String (ISO datetime) | Yes | |
| `isAcknowledged` | bool | Yes | Default `false` |
| `isResolved` | bool | Yes | Default `false` |

**Example:**
```json
{
  "alertId": "alert_001",
  "tripId": "trip_001",
  "affectedDestinationId": "dest_shimla",
  "previousRiskLevel": "low",
  "currentRiskLevel": "high",
  "title": "Heavy rainfall and landslide risk",
  "message": "Weather conditions in Shimla have worsened. Continuing outdoor activities is not recommended.",
  "recommendedAction": "adapt_trip",
  "createdAt": "2026-08-11T14:00:00+05:30",
  "isAcknowledged": false,
  "isResolved": false
}
```

## Entity Relationship Summary

```
Destination ──────< Trip >────── Itinerary ───< ItineraryDay ───< ItineraryItem
                    │
                    ├──< SafetyCondition
                    ├──< RiskAlert
                    ├──< TimelineEvent
                    ├──< Expense
                    ├──< Memory
                    └──  TripSummary (computed)

AlternativeDestinationOption ──> Destination (reference)
DemoScenario ──> Destination, RiskAlert (templates)
```
